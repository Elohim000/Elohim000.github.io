## 关于我

Hi，我是 **Elohim000**。

这里是我用来整理学习资料和记录日常想法的小站。现在的内容主要是课程复习笔记、思维导图和一些随笔，更多时候是给未来的自己留一份能找回来的记录。

### 目前在整理

- **课程笔记**: 现代控制理论、移动机器人、运动控制系统、大学物理等
- **复习资料**: 把零散知识整理成更容易回看的结构
- **个人记录**: 偶尔写一点生活、学习和阶段性的想法

### 关于本站

本站使用 [Hexo](https://hexo.io) 框架 + [Butterfly](https://butterfly.js.org) 主题搭建，托管于 GitHub Pages。

- 左侧栏可以看到最近文章、分类标签
- 顶部导航可进入归档、标签、分类和关于页面
- 文章会按分类和标签归档，方便之后查找
