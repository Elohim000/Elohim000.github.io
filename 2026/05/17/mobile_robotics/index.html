移动机器人课程复习思维导图

复习主线

移动机器人课程可按三条主线复习：

  1. 运动：腿式结构、轮式移动机构、运动学、机动性、工作空间。
  2. 感知：传感器分类、编码器、GPS、双目视觉、相机标定、图像处理。
  3. 定位与导航：信任度、马尔可夫定位、路径规划、避障。

轮式移动机器人

四种基本轮形

轮形 自由度/特征 复习重点
标准轮 两个自由度：绕轮轴转动、触地点转动 常用于差动驱动、同步驱动等结构
小脚轮 三个自由度：绕轮轴、触地点、脚轮轴旋转 常作随动/支撑轮，不一定计入可操纵度
瑞典轮 三个自由度：绕轮轴、辊子、触地点转动 可实现全向/麦克纳姆式运动
球形轮 理论上全向，但悬挂和驱动实现复杂 工程上难度较高
标准轮 小脚轮 瑞典轮 球形轮

复习要点：

  • 标准轮最重要，后续机动性、非完整约束、差动驱动都会用到。
  • 小脚轮和无动力随动轮通常不计入“可操纵度”。
  • 瑞典轮/麦克纳姆轮用于增强全向移动能力。

机动性

移动机器人的机动性/活动能力来自两部分：

  1. 受滑动限制后的可用活动性。
  2. 由操纵标准轮提供的附加自由度。

记：

总机动性：

活动性程度

  • 机器人能直接通过控制轮子转动来改变的运动自由度数量。
  • 对于采用标准轮的机器人，通常等于其能独立控制速度的轮子组数量。

可操纵度

  • 机器人能独立控制转向机构的数量。
  • 不包括仅为改变自身方向而存在的自由旋转脚轮。
  • 等于可独立控制转向角的转向轮数量；无动力的随动轮不计入。

复习要点：

  • 看“轮子转速能独立控制几组”。 -看“转向角能独立控制几个”。
  • 总机动性不是简单数轮子，而是看可控的运动自由度。

移动机器人的工作空间

自由度、机动性、活动性程度

  • 机动性 = 控制自由度。
  • 活动性程度 = 可微的自由度。

相关概念：

概念 含义
DOF 自由度，机器人达成不同姿态的能力，偏位置自由度
DDOF 可微自由度，机器人沿不同路径运动的能力，偏速度自由度
活动性程度

关系式：

完整机器人

完整机器人可理解为：没有非完整运动学约束的机器人。

  • 完整运动学约束只依赖位置变量。
  • 非完整运动学约束通常依赖位置变量的微分，即速度关系。
  • 固定的、可操纵的标准轮会产生非完整约束。

复习要点：

  • 看到“完整/非完整”时，先判断约束是否涉及速度或微分项。
  • 轮式移动机器人常见重点是非完整约束。

感知

传感器分类

本体感受传感器

测量机器人自身内部值，例如：

  • 位置、速度、轮负载、机器人方向、电池状态

外部受体传感器

从机器人环境获取信息，例如：

  • 到物体的距离、周围光强度、可分辨的环境特征

被动传感器

测量从环境进入传感器的能量。

  • 例：普通摄像头、环境光传感器等。

主动传感器

主动发射能量，再测量环境响应。

  • 优点：性能通常更强。
  • 注意：可能对环境产生一定影响。

编码器

增量式编码器

增量式编码器通过编码盘上的光栅或槽产生脉冲信号：

  • 统计脉冲数可得到相对转角或位移。
  • 常使用相差 的 A、B 两相信号。
  • 根据 A、B 两相信号的先后关系判断转动方向。

复习要点：

  • 增量式编码器只能获得相对变化量。
  • 断电或丢脉冲后，需要重新校准或回零。
  • A/B 相的关键是相位差与方向判断。

绝对式编码器

绝对式编码器的每一个角度位置都有唯一编码：

  • 可以直接读出当前位置。
  • 常使用格雷码。

选择格雷码的原因：

  • 相邻两个码之间只有一位不同。
  • 当角度发生微小变化时，只会有一位发生变化。
  • 可减少数字转换过程中的逻辑混淆和误读，提高编码可靠性。

张正友标定法

步骤：

  1. 打印一张模板并贴在一个平面上。
  2. 从不同角度拍摄若干张模板图像。
  3. 检测出图像中的特征点。
  4. 求出摄像机的内参数和外参数。
  5. 求出畸变系数。
  6. 优化求精。

复习要点：

  • 内参数回答“相机自身如何成像”。
  • 外参数回答“世界坐标如何转换到相机坐标”。
  • 标定的最终目标是把像素坐标与空间几何关系对应起来。

定位和导航

信任度

信任度用于表示机器人对自身位置的相信程度。

  • 单假设信任度：机器人假定其唯一位置。
  • 多假设信任度：机器人描述它位置的不确定度。

复习要点：

  • 定位问题不是只求一个点，而是常常求一个概率分布。
  • 多假设表示能更好处理感知不确定性与环境相似性。

马尔可夫定位

马尔可夫定位采用显式的离散形式，表示状态空间中所有位置的概率。

通常用有限多个栅格或拓扑图表示环境：

  • 可能状态（位置）为有限多个栅格或拓扑节点。
  • 每次更新时，整个空间中每个状态单元的概率都得到更新。
  • 本质是对概率分布的递推更新。

RRT

RRT 是基于随机采样的路径规划方法。

基本步骤：

  1. 以出发点为根节点。
  2. 随机产生新节点。
  3. 找最近已有节点。
  4. 尝试连接。
  5. 若无碰撞则加入树。
  6. 重复直到连接目标。

复习要点：

  • 图搜索类方法：先建图，再搜索。
  • 势场法：把目标/障碍转换成力场，但要注意局部极小值。
  • RRT：适合高维空间与复杂约束，但路径可能不够平滑。

避障

常见的避障算法整理如下：

算法 核心思想 典型特点
Bug1 完整绕障碍物一圈，再从离目标最近处离开 效率低，但保证可达目标
Bug2 沿一侧绕障碍物，回到起点—目标连线时离开 路径较短，但可能失效
VFH 栅格地图转一维直方图，选择开放通道 适合局部避障
VFH+ 在 VFH 基础上考虑轨迹/圆弧运动 考虑动力学更强
气泡带 构造一串无碰撞自由空间 强调安全空间
CVM 在速度空间考虑约束并选择最优速度/道路 狭窄区域性能较好，但仍可能有局部极小
DWA 在动态窗口内搜索速度，保证碰撞前能停下 兼顾运动学与实时避障

复习要点：

  • Bug 类算法：规则简单，常用于理解“绕障”基本逻辑。
  • VFH/VFH+：局部传感器数据 → 直方图 → 选择通道。
  • DWA/CVM：在速度空间内做选择，更接近实际机器人运动约束。
